# 🏕️ Camping Frailejón

Sitio web oficial de Camping Frailejón — Páramo, neblina y aventura.

## Estructura

- `index.html` — Página principal
- `salidas.html` — Rutas de trekking con mapa
- `actividades.html` — Eventos y talleres
- `galeria.html` — Galería de fotos
- `nosotros.html` — Información del camping
- `admin/` — Panel de administración (Decap CMS)
- `content/` — Posts generados por el CMS
- `assets/` — CSS, JS, imágenes e iconos


## Tecnologías

- HTML5 + CSS3 (estilo páramo/neblina)
- Leaflet.js (mapas interactivos)
- Decap CMS (gestión de contenido)
- Netlify (hosting gratuito)
